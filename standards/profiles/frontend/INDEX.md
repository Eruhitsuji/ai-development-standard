# Frontend Profile

Use this profile for user-facing web or app frontends.

- Verify responsive layouts for affected views.
- Check loading, empty, error, and disabled states.
- Keep visible text inside its container at supported breakpoints.
- Prefer existing design system components.
- Avoid unrelated visual redesigns during functional tasks.

Review focus: accessibility, keyboard interaction, mobile layout, visual regressions, and user-visible copy.
