## Claude Code Specific Rules

- Use Plan Mode before changing multiple standard areas or public templates.

  explicitly instructed.
- Prefer repository scripts over ad hoc validation commands.
- Ask before destructive operations, repository-wide migrations, or ruleset
  changes.
