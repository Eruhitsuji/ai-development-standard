# Foundation Issue Templates

Use these files as starter bodies for the first issues created after project
initialization or existing project adoption.

The issue list is intentionally small. It should establish ownership, commands,
CI, architecture, task management, and activation gates before normal feature
development starts.

## Templates

- `new-project.md`: foundation issue set for repositories created from a
  template.
- `existing-project-adoption.md`: foundation issue set for repositories adopting
  the standard after code and workflows already exist.

Each generated issue should still receive a concrete owner, executor, write
scope, verification method, and acceptance criteria before implementation.
